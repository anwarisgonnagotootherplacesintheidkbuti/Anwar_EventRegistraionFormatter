
# Student Event Registration Formatter

## Description
This Python program collects student information and event details. It formats the student's name, section, event name, and date to make the registration information clear and organised.

## Features
- Formats the full name using title()
- Displays the full name in uppercase using upper()
- Removes extra spaces using strip()
- Formats the event date using datetime
- Displays the programming language and features used

## Language Used
Python

## Features Used
- strip()
- title()
- upper()
- datetime
- strftime()

## Sample Output
Name: Juan Dela Cruz
Name Code: JUAN DELA CRUZ
Section: MAGNESIUM
Event: Science Fair
Event Date: June 3, 2026
